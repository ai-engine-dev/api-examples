# AI All-in-One

One API key for 36+ endpoints: OCR, face analysis and search, background removal, face swap, photo restoration, colorization, NSFW detection, sentiment and emotion analysis.

- **Endpoints**: `POST https://ai-all-in-one.p.rapidapi.com/v1/...` (the examples call `/v1/ocr` and `/v1/sentiment`)
- **Response**: same format as the single-purpose API of each endpoint
- [RapidAPI Page](https://rapidapi.com/ai-engine-ai-engine-default/api/ai-all-in-one)
- [Full Documentation](https://ai-engine.net/apis/all-in-one?utm_source=github&utm_medium=referral&utm_campaign=api-examples)

## Getting an API Key

1. Go to [AI All-in-One on RapidAPI](https://rapidapi.com/ai-engine-ai-engine-default/api/ai-all-in-one)
2. Click **Subscribe** (free tier available)
3. Copy your API key and replace `YOUR_API_KEY` in the examples
